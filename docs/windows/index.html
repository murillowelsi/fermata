Instalar no Windows

O Fermata para Windows é portátil: não tem instalador, é só extrair e abrir. Na primeira vez, o Windows pede uma confirmação.

Baixar para Windows.zip · Windows 10 e 11, 64 bits
O download começou: Fermata-Windows-x64.zip. Não começou? Baixar de novo.

  1. Extraia o .zip

    Nos Downloads, clique com o botão direito em Fermata-Windows-x64.zip ▸ Extrair tudo… Guarde a pasta onde quiser, por exemplo em Documentos.

  2. Abra o Fermata.exe

    Dentro da pasta, dois cliques. Dica: com o Fermata aberto, clique com o botão direito no ícone da barra de tarefas ▸ Fixar na barra de tarefas.

  3. Na tela azul: Mais informações ▸ Executar assim mesmo

    A tela “O Windows protegeu o computador” aparece só na primeira vez. Não clique em “Não executar”.

Os atalhos são os mesmos do Mac, com Ctrl. Se Alt+Shift trocar o idioma do teclado em vez de abrir uma paleta, desligue esse atalho do Windows em Configurações ▸ Hora e idioma ▸ Digitação ▸ Configurações avançadas de teclado.

Por que o Windows avisa? É seguro?

O Windows mostra esse aviso para apps sem uma assinatura digital paga. O Fermata é gratuito e ainda não tem essa assinatura. O código-fonte é aberto e pode ser conferido no GitHub. Baixe sempre por esta página ou pela página de versões do projeto.

Como atualizar para uma versão nova

Feche o Fermata, baixe o .zip novo e extraia por cima da pasta antiga, escolhendo substituir os arquivos. Suas partituras não ficam nessa pasta e não são apagadas.
